# 🧟 Zombie Survival

A browser-based zombie survival game built with **HTML, CSS, and JavaScript**.

> 🚧 **Status: Currently in Development**

## 🌐 Play Online

Play the game on **GitHub Pages**:

**[Play Zombie Survival](https://amiralidlb93-hash.github.io/zombie-survival/)**

## 🎮 Controls

| Key / Input | Action |
|---|---|
| `W` `A` `S` `D` | Move |
| Mouse | Aim |
| Hold Left Click | Shoot |

## ✨ Features

- Zombie survival gameplay
- Mouse aiming and shooting
- Health, score, and wave counters
- Increasing difficulty
- Support for English and Persian keyboard layouts

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## 🚧 Development

Zombie Survival is currently in development. Gameplay, visuals, and features may change as the project improves.
